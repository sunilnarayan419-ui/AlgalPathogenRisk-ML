# Data analysis guide

## 1. Inspect the GEO series matrix

```powershell
python scripts\audit_geo_matrix.py --input data\raw\GSE128981_series_matrix.txt.gz `
    --output reports\geo_metadata_audit.json --manifest-dir data\metadata --gse128981-batch-rule
python scripts\audit_dataset.py --series-matrix data\raw\GSE128981_series_matrix.txt.gz --out reports\audit
```

**Observed on the supplied file:** 21 samples; organism *C. reinhardtii*; assay RNA-Seq; genotype groups
srta mutant 11, SRTA complemented 6, SRTA WT 4; strain groups Elow47 4, UVM4 4, UVM11 7, UVM11-C1 3,
UVM11-C9 3; **expression table empty**. The audit therefore reports that no expression analysis is
possible from this file and lists what the data do and do not support.

## 2. Obtain the expression values

`scripts/download_geo.py` fetches `GSE128981_FPKMs.replicates.v2.tsv.gz` (needs network; not run by the
authors). Inspect its header before analysis; if it has an annotation column pass `--drop-columns`.

## 3. Exploratory analysis and group comparison

```powershell
python scripts\run_analysis.py --fpkm data\raw\GSE128981_FPKMs.replicates.v2.tsv.gz `
    --metadata data\metadata\sample_metadata_gsm.csv --out reports\exploratory `
    --contrast UVM4 Elow47 --batch-col batch
```

Outputs: `qc_summary.csv`, `sample_correlations.csv`, `log2_fpkm.csv`, `pca_scores.csv`, `pca.png`,
`pca_by_batch.png`, `distributions.png`, `exploratory_report.{json,md}`, and for a contrast
`de_log2fpkm_<a>_vs_<b>.{csv,json}`. Exit codes: 0 ok, 1 invalid input, 3 contrast refused.

Which contrasts are interpretable: batch 1 holds Elow47, UVM4 and UVM11 reps 1-4; batch 2 holds UVM11 reps
5-7 and both complemented lines. WT vs complemented has no shared batch (only bridged via UVM11), so it is
refused by default. See [count-based DE](count_based_de.md) for the estimability audit.

## 4. Verified demonstration on synthetic data

`tests/fixtures/SYNTHETIC_fpkm_gse128981_layout.tsv` is random data in the real sample layout (generated by
`scripts/make_synthetic_fixture.py`, seed 7) with planted effects in 15 genes for UVM4. In the verified run,
`--contrast UVM4 Elow47` flagged 16 genes at BH < 0.05 (15 planted + 1 chance hit) and `UVM11-C1` vs `Elow47`
was refused with exit code 3. **These numbers describe synthetic data and are not biological results.**

## 5. Power and design

`/api/v1/experiments/power-analysis` and `app/experiments/power.py` give sample sizes for continuous and
binary endpoints; with 3-4 replicates per strain only large effects are detectable.
